# BMW-Sales-Analysis
BMW Sales Data Analysis

This project focuses on analyzing BMW sales data to identify sales trends, regional performance, pricing patterns, and customer preferences. The analysis was performed using univariate and multivariate analysis techniques on a dataset containing 50,000 rows and 11 columns.

Objectives
Identify the highest-selling BMW models
Analyze sales performance across different regions
Study price variations across years
Understand the relationship between engine size and mileage
Dataset Information
Total Rows: 50,000
Total Columns: 11
Categorical Columns: 5
Numerical Columns: 5
Geographical Columns: 1
Analysis Performed
Univariate Analysis
Multivariate Analysis
Sales Trend Analysis
Regional Sales Comparison
Engine Size vs Mileage Analysis
Key Insights
White-colored BMW models showed the highest frequency.
Asia, Europe, and North America recorded strong sales performance.
Certain BMW models achieved significantly higher sales volumes in specific regions.
Engine size showed an impact on vehicle mileage.
Tools Used
PowerPoint
Data Analysis Concepts
Data Visualization Techniques

Conclusion

The analysis indicates that BMW achieved strong sales performance in regions such as Asia, Europe, and North America. The project provides valuable insights into customer preferences, pricing trends, and sales distribution across regions.
